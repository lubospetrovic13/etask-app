# Nástroje

Nástroj je lacnejší než odsek v dokumentácii: odpovie presne a nezje kontext.

| nástroj | odpovedá na |
|---|---|
| `pfdoc` | kde to je napísané (a vypíše len tú kapitolu) — [[Kontext a tokeny]] |
| `pflint` | čo je v sieti zle (štruktúra, grid, mŕtve polia, race tlačidla) |
| `pfgroovy` | či akcie vôbec prejdú parserom |
| `pfi18n` | či má každý viditeľný text preklad |
| `pfview` | či frontend vykreslí to, čo sieť pýta |
| `pfapi` | aké metódy sa dajú zavolať z akcie — [[Inventár metód]] |
| `pfsync` | či engine drží to isté, čo repozitár |
| `pfseed` | kto má akú rolu (deklaratívne) |
| `pfnew` | nová appka zo skeletu, ktorý už vzory obsahuje |
| `pfapp` | appka z vlastného repa — [[Šablóna vs nasadenie]] |
| `pftest` | testy samotných nástrojov |
| `up.sh` | celý stack, aj `--docker` |

Pravidlo: **keď nástroj a engine nesúhlasia, opravuje sa nástroj.**
