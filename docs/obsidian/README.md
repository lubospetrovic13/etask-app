# Ako otvoriť

Tento priečinok je **Obsidian vault**: otvor `docs/obsidian`
cez *Open folder as vault*. Graf (Ctrl+G) ukáže, ako do seba zapadá práca AI
agenta na tomto repozitári — uzly sú poznámky, hrany sú odkazy v dvojitých hranatých zátvorkách.

Začni pri [[Ako agent pracuje]].

Poznámky sú zámerne krátke a odkazujú do dokumentácie príkazom `pfdoc`, nie
kópiou textu — dve kópie toho istého sa vždy rozídu.
